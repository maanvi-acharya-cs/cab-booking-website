# 🚀 Cab-Booking Website 

A clean, responsive, and user-friendly frontend project built during my 2nd year of Computer Science studies.

---

## ✨ Features
* 📱 **Fully Responsive Design:** Works seamlessly on mobile, tablet, and desktop screens.
* 🎨 **Modern UI/UX:** Interactive layouts and intuitive user experience.
* ⚡ **Key Functionalities:** Interactive Navigation Bar, Form Validation.

---

## 🛠️ Tech Stack
* **HTML5** - Structure and semantic elements
* **CSS3** - Custom styling, Flexbox, and CSS Grid
* **JavaScript (ES6+)** - Dynamic DOM manipulation and interactivity
